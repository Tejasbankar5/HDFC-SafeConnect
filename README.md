

# HDFC SafeConnect – Bank Management System

HDFC SafeConnect is a simple Python and SQL-based banking management system. It allows users to manage bank accounts, perform basic banking operations, and store records securely in a database.

---

## Features

* Create new account
* View account details
* Deposit money
* Withdraw money
* Balance check
* Store and manage data using SQL database

---

## Technology Used

* Python
* MySQL (or SQL database)

---

## How It Works

* User interacts through the Python program
* System performs banking operations
* Data is stored and retrieved from SQL database
